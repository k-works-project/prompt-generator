# 構造化プロンプト自動生成ツール (Prompt Generator)

非エンジニアや生成AIに慣れていないユーザーでも、直感的な入力からプロ品質の構造化プロンプト（Markdown形式）を簡単に作成できるWebツールです。

---

## 概要

生成AIへの指示出しにおいて、「指示が雑で意図通りの回答が得られない」「プロンプト構築の型（役割・前提・制約事項など）を覚えるのが大変」という課題を解決するために開発しました。

口語的な日常会話レベルの入力を行っても、JavaScriptの整流化ロジックによって自動的にプロ品質の指示文・敬語へと補正し、最適化されたプロンプトを出力します。

---

## 主な機能・工夫した点

- **直感的なフォーム設計**: 役割・依頼・前提・条件・出力形式の5項目に分かれており、迷わず入力可能。
- **口語表現の自動整流化**: 「〜っぽく」「〜まとめてほしい」などの曖昧な入力を、プログラム側で自然な指示文（「〜形式に整理・作成してください。」など）に置換・整形。
- **文末の自動敬語統一**: 条件欄の入力末尾を「〜出力してください。」「〜明記してください。」などの丁寧な表現に自動統一。
- **自動ルール適用（オプション）**: チェックボックスを選択するだけで、「文字起こしのケバ取り」「挨拶・解説の除去」といった実用的な制約事項を即座に適用。
- **ワンタップコピー**: 生成されたプロンプトを1クリックでクリップボードにコピー可能。
