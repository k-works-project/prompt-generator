# プロンプトジェネレーター (プロンプト自動生成ツール)

非エンジニアでも直感的に操作できる構造化プロンプト自動生成Webアプリケーションです。

🚀 デモ (公開URL)
----------------

[プロンプト自動生成ツールを試す](https://k-works-project.github.io/prompt-generator/portfolio/)

🛠 主な機能
----------------

* **5項目の構造化入力**: 役割・依頼・前提・条件・出力形式に分けて直感的に入力
* **口語表現の自動整流化**: 雑な入力テキストをプロ品質の明確な指示文へ自動補正
* **敬語統一処理**: 条件欄の文末を「〜してください」などの丁寧語に自動変換
* **自動ルール適用オプション**: ケバ取りや挨拶除去などの実用的な制約事項を一括追加
* **ワンクリックコピー**: 生成された構造化プロンプトをクリップボードに即座にコピー

💻 使用技術
----------------

* HTML5
* CSS3 (レイアウト設計・レスポンシブデザイン)
* JavaScript (Vanilla JS / 外部ライブラリなし)

📌 こだわりポイント
----------------

* ライブラリに頼らず、純粋なJavaScriptのみで正規表現による文章整流化ロジックを実装しました。
* 非エンジニアでも迷わず使えるUIと、AIが誤解しにくいプロンプト出力の両立を追求しています。
